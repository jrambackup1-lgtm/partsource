## Variant: Family faceted catalog

### Design stance

Treat the family page as a precise catalog browser: compact facets, a stable configuration table, and one explicit selected-configuration panel.

### Key choices

- Layout: family header, left facet rail, central table, right selection inspector.
- Typography: existing Inter/system family with monospace configuration references.
- Color: current PartSource slate/white system with restrained green trust status.
- Interaction: change thread, select rows, load a known identifier, add the selected configuration to a local BOM.

### Trade-offs

- Strong at: scanning many variants, comparing specs, preserving family context, known-ID highlighting.
- Weak at: initially dense for users who do not know which attributes matter.

### Best for

Mechanical engineers and repeat users who want direct control and fast comparison.
