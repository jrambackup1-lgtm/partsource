# Compare-first specification lab

**Status:** Wayfinder prototype. Not a requirement, catalog release, BOM-readiness, or equivalence tool. The displayed records are illustrative comparison fixtures, not approved product facts.

## Question

Does `Differences only` reduce variant scanning and wrong selection without making configurations look interchangeable?

## Test

1. Ask user to explain every meaningful difference.
2. Ask which unknown blocks selection.
3. Ask whether comparison implies equivalence.
4. Switch to all facts and check whether hidden common facts were needed.
5. Repeat at 320 px and keyboard only.

## Pass signal

Faster correct difference recall, no false-equivalence language, unknowns noticed, and baseline understood.

## Fail signal

User chooses from color alone, misses unknowns, treats records as substitutes, or needs all facts by default.
